# Distribución RPA TotalFOB

Repositorio de distribución de paquetes y canales firmados del robot. El canal TEST es experimental y no representa una publicación de producción. Las aplicaciones verifican la firma y las huellas antes de activar versiones.

No incorporar credenciales, claves privadas, datos consultados, archivos descargados, cookies ni registros operativos. El código fuente se mantiene en el repositorio privado del proyecto.
